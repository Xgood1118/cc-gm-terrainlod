# terrainlod

按三角形预算选级、且接缝不出裂缝的地形四叉树 LOD 选择器。只使用
Python 标准库，保留骨架中的公开名字与签名（`QuadNode`、
`build_quadtree`、`select_lod`、`stitch_seams`）。

- 实现：`terrainlod/core.py`
- 命令行：`terrainlod/cli.py`
- 题面：`prompt.txt`
- 自测：`python -m pytest tests -q`

## 模型

- 高度图是一张 `rows × cols` 的规则网格，行列数都不必是 2 的幂，
  也接受矩形与单格地图。
- 每个四叉树节点覆盖一个半开矩形格子区域 `[x, x+ext_w) × [y,
  y+ext_h)`；叶子集合始终是整块地形格子的一个**无重叠、无空洞**
  的划分（非 2 次幂尺寸按向上取半切分，零尺寸子节点不会产生）。
- 节点用一张固定分辨率的粗网格（每侧最多 2 个四边形，即 8 个
  三角形）近似其覆盖区域，`size` 为网格每侧四边形数，因此节点的
  三角形成本恰为 `2 * size * size`。细分 = 用 4 个更小的块替换
  一个块，成本按约 3 倍/级增长，预算机制因此有实际约束力。
- 网格顶点跨越格子边界取整数格子坐标（区域 `[x, x+w)` 的顶点为
  `x .. x+w`），相邻节点共享同一条边界上的顶点坐标，缝合时按坐标
  一一焊接。

### 几何误差（严格单调）

节点误差 = 覆盖区内每个高度采样点相对节点角点**双线性插值面**的
最大高度偏差，再与子节点误差取最大值并叠加深度小量
`ERROR_EPS = 1e-9`：

```
error(node) = max(自身偏差, max(error(child))) + ERROR_EPS
```

因此任意父节点误差都**严格大于**子节点，全平地形（自身偏差恒为
0）也不例外；误差序列在任意根→叶路径上严格单调。

### 预算选级（确定性、不超支）

`select_lod(root, tri_budget)` 从根开始维护一个前沿集合，用最大
误差优先堆（误差并列时按构建序号）反复细分：仅当节点 SSE 达到
阈值、且细分后的总成本仍不超过预算时才细分，否则**降级保留**为
叶子。预算连根节点都无法容纳时返回根节点（理论下限）。

- 三角形总数在任何预算下都不超支；
- 选择只依赖误差与构建序号，同一预算两次调用结果完全一致；
- 只要还存在买得起的细分就不会停止——预算未用完时，剩余额度必然
  连最便宜的一次细分都买不起，不存在“没用完就停”的退化。

### 接缝缝合（无 T 型接点）

`find_seams` 借助“格子→叶子”占用索引枚举所有层级差边界；
`stitch_seams` 对每条边界取两侧网格顶点键的并集，把对侧存在而
本侧缺失的顶点补入对应叶子的网格。补点之后边界顶点一一对应，
T 型接点被焊接消除，裂缝不再产生。

- 返回 `(verts, extra)`：`verts` 为全局去重后的 `(i, j, height)`
  顶点列表（确定性排序，外缘越界坐标钳制取高度）；
- `extra` 为向各叶子网格插入边界顶点的总次数，每个 T 型接点对应
  一次插入，可直接统计；全细化（无层级差）时为 0。

### 极端视角参数

`build_quadtree(h, depth, view={...})` 可选计算屏幕空间误差
（`distance / fov / screen_height`），`select_lod(...,
sse_threshold=...)` 据此冻结足够远的节点。极近视角细分更细、极远
视角冻结在根附近，且结果仍然确定；不传阈值时视角不影响选择。

## 运行结果

题目要求的命令（8×8 数据、深度 3、预算 20000，地图被全细化）：

```
python -m terrainlod.cli data/heightmap.json --out lod.json
```

| 指标 | 数值 |
| --- | --- |
| 叶子数 | 64 |
| 三角形数 | 128 |
| 预算使用率 | 0.64%（128 / 20000，小图全细化后的自然上限） |
| 缝合额外顶点数 | 0（同深度相邻，无层级差边界） |
| 去重后总顶点数 | 81 |

同一地图在较小预算下的混合 LOD 结果（可见缝合统计）：

| 预算 | 叶子数 | 三角形数 | 预算使用率 | 缝合额外顶点 |
| ---: | ---: | ---: | ---: | ---: |
| 20 | 1 | 8 | 40.0% | 0 |
| 40 | 4 | 32 | 80.0% | 0 |
| 80 | 34 | 80 | 100.0% | 136 |
| 100 | 34 | 80 | 80.0% | 136 |
| 128 | 64 | 128 | 100.0% | 0 |

预算 100 停在 80 三角形是确定性降级：剩余 20 额度买不起任何一次
细分（下一级每块 8 三角形、一次细分净增 24）。

## 规模

256×256 合成多尺度高度图、最大深度 8：

| 预算 | 叶子数 | 三角形数 | 预算使用率 | 缝合插入次数 | 选级+缝合耗时 |
| ---: | ---: | ---: | ---: | ---: | ---: |
| 20000 | 2500 | 20000 | 100.0% | 233943 | 约 0.4 s（< 3 s） |
| 40000 | 10027 | 39992 | ≈100.0% | 600833 | — |

预算翻倍后叶子数约为 4 倍：每次细分把一个 8 三角形块换成 4 个，
成本约按 4 倍增长，因此翻倍预算可再深入约一个层级，叶子数随之
约 4 倍增长，结果可解释；两种预算下剩余额度都不足以再做任何一次
细分。
